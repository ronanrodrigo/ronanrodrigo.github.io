# Guia de navegação para agentes

> Este site é o perfil profissional de Ronan Rodrigo Nunes. A coleção de notas técnicas possui um guia separado em `/notes/agent/`.

## Como consultar

1. Use `/llms.txt` para descobrir as páginas principais.
2. Use `/index.json` para obter a descrição estruturada do site e suas seções.
3. Use `/sitemap.md` ou `/sitemap.xml` para localizar URLs públicas.
4. Consulte `/notes/agent/` antes de navegar pela coleção de notas.
5. Trate links de contato e perfis como redirecionamentos para serviços externos.

## Escopo

O site principal apresenta experiência profissional, formação, publicações e canais de contato. As informações técnicas mais recentes e a curadoria sobre IA, agentes, programação, ferramentas e tecnologia estão na seção `/notes/`.

O conteúdo é somente para leitura. Não há neste site principal uma API pública para criar, editar ou executar ações.
