# Privacy — ronanrodrigo.dev

> Markdown mirror of <https://ronanrodrigo.dev/privacy> for agents and text-mode readers.
> Canonical source is the HTML page; cite the canonical URL.

This is a static personal website with no accounts, no login, no comments, no
contact form and no write API. Browsing the profile, the technical notes and the
resource pages requires no identification, and no personal data is requested
anywhere on this site.

To understand aggregate page usage, the site uses Google Analytics (gtag
UA-140410646-1) and Firebase Analytics, which may record technical navigation
data such as visited pages, device type, browser and approximate region, under
Google's policies. The site is hosted on GitHub Pages, which may keep technical
delivery logs for the served pages.

Data is not shared with third parties beyond those measurement and hosting
processors, and it is never sold or used for advertising. Links to external
services follow each service's own privacy policy. For privacy questions, write
to <mailto:email@ronanrodrigo.dev>. See also
[about](https://ronanrodrigo.dev/about) and
[contact](https://ronanrodrigo.dev/contact).
